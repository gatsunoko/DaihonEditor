# 台本制作エディタ

`index.html` をブラウザで開くと使える、LocalStorage保存対応の台本制作エディタです。

## 主な機能

- `：` または `:` より前を話者名、後ろを本文として扱います。
- 話者名は自動検出され、未登録の場合は背景色が自動割り当てされます。
- 話者登録パネルから話者を追加でき、話者背景色と本文色はあとから変更できます。
- 行番号、話者名の色付き太字表示、ト書き・効果音・BGM種別に対応しています。
- 本文の一部を選択して、太字や文字色を付けられます。
- 単語とふりがなを登録すると、本文・書出し・リッチコピーで `単語（ふりがな）` と表示できます。表示は右サイドバーで切り替えられます。
- LocalStorageへ自動保存します。
- 「AI接続」を有効にすると、CodexやGPT WorkからMCPで台本を読み取り・検索・編集できます。AIの変更も保存され、Undoで取り消せます。
- 一度JSON保存したあとは、編集内容を同じJSONファイルへ自動保存します。
- 台本ごとの識別IDを使い、別の台本JSONを選んだときは上書きを保存前にブロックします。
- 指定したフォルダへ10分ごとに世代バックアップを作り、台本ごとに最新30件を保持します。
- JSON保存、JSON読込、TXT書き出し、Google Docs用DOCX書き出しができます。
- DOCX書き出しでは、話者名を登録色の太字で出力し、背景色は付けません。
- 書出し設定で、台詞行の間に空行を入れるか、備考も書き出すか、備考範囲に区切り線を入れるかを切り替えられます。
- Google Docs貼付けプレビューから、話者名の色と太字を保ったリッチコピーができます。
- 「話者のみコピー」で、表示中のセクションに登場する話者を行順の改行区切りでコピーできます。「全て表示」中は全セクションが対象になり、同じ話者の重複も維持します。
- 全文検索、全文置換、話者名だけ置換、本文だけ置換ができます。
- 右サイドバーに本文文字数の全体合計と表示中セクション合計を表示します。

## 操作

- 通常の自動保存状態は「JSON保存」「バックアップ設定」にカーソルを重ねると確認できます。手動保存の完了や再設定・失敗の通知は6秒で消え、再設定などが必要な間は該当ボタンが黄色になります。
- 最初に「JSON保存」でフォルダと新しいファイル名を指定すると、以後は入力が止まってから約2秒後に同じJSONへ自動保存します。同名ファイルが既にある場合は作成を拒否します。
- 保存先の設定後は「JSON保存」で現在のJSONへ直接保存します。「別名保存」は必ず新しいファイルを作り、新しい台本IDを発行します。
- 「バックアップ設定」でバックアップ用フォルダを一度選ぶと、10分ごと・台本切り替え前・JSON保存先の変更前に日時付きJSONを作成します。古いものから整理し、台本ごとに最大30世代を保持します。
- JSON保存・別名保存では既存ファイルを保存先として選択できません。同名ファイルがある場合は、別の名前を指定してください。
- JSON読込では読み込んだファイル自体を現在の保存先として記憶します。識別IDがない旧形式JSONは、実際に読み込んだ元ファイルだけを確認後に新形式へ移行できます。
- 新規作成または別のJSONを読み込んだときは、以前のJSONを上書きしないよう自動保存先を解除します。新しい保存先は「JSON保存」で設定してください。
- 新規作成や別のJSONへの切り替え前には、現在のJSON自動保存が完了するまで待機します。権限切れなどで保存できない場合は、内容を守るため切り替えを中止します。
- 行内で `Enter` を押すと次の行を追加します。
- 本文をドラッグ選択して、下部の `B` や色ピッカーで部分装飾できます。
- 本文の編集や部分装飾は、別の行へカーソルを移した後も `Undo` または `Ctrl+Z`（Macは `Command+Z`）で元に戻せます。
- 行番号をクリックすると行を選択できます。複数行を選択してコピー、カット、貼り付けができます。
- 備考欄をクリックすると、その行にカメラワークなどの備考を直接入力できます。複数行を選択してから選択範囲内の備考欄をクリックすると範囲備考になり、「終点」ボタンまたは下端ハンドルで終了行を変更できます。
- 行番号をドラッグすると行を移動できます。選択行がある場合は、選択行をまとめて移動できます。
- 複数行テキストを貼り付けると、各行を自動で分割して取り込みます。
- 新しいセクションは、選択中のセクションのすぐ右に追加されます。「全て表示」中は末尾に追加されます。
- セクションタブをダブルクリックすると名前を変更できます。
- 右サイドバーの「ふりがな」で単語と読みを登録します。同じ単語を再登録すると読みを更新でき、表示をオフにすると本文・TXT・DOCX・リッチコピーのすべてからふりがなが外れます。
- 話者一覧の左端ハンドルをドラッグすると、話者の並び順を変更できます。
- 話者一覧の名前（鉛筆マーク）をクリックすると、全セクションの同じ話者名をまとめて変更できます。色と並び順はそのまま引き継がれ、`Undo` で元に戻せます。空の名前や登録済みの名前には変更できません。
- 話者一覧の削除ボタンで話者を削除すると、本文は残して該当行の話者欄だけ空になります。

## 本文の取り消しの検証

Python版PlaywrightとChromiumが利用できる環境で、`python tests/check-body-undo.py` を実行すると、行移動後の取り消しや部分装飾・貼り付け・日本語入力との組み合わせをブラウザで確認できます。

## Codex・GPT Workとの接続

Node.js 22以降を用意し、このフォルダで `npm.cmd install`、`npm.cmd start` を実行します。台本の画面を再読み込みし、「AI接続」→「接続」を押してください。直接開いた `index.html` でも接続できます。

CodexのMCP登録、GPT Work用プラグインのインストール、Web版からの接続方法は [接続手順](mcp/README.md) を参照してください。
